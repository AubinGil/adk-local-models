# adk-local-models

A Google ADK model class for local OpenAI-compatible servers (vLLM, Ollama, llama-server) with no LiteLLM in the
path: one `BaseLlm` subclass, three documented profiles, exact request and reply bytes hashed into every response.

Status (2026-10-28): design fixed in `AGENTS.md`; brief 001 written, not started. Parked behind harness-core.
