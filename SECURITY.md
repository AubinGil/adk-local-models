# Security

To report a vulnerability privately, open the repository's **Security and quality**
tab on GitHub and select **Report a vulnerability**. Provide enough detail to
reproduce and assess the issue. Please do not disclose sensitive details in a
public issue. See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

The adapter sends requests to the configured `base_url`; it does not configure or manage model servers.
